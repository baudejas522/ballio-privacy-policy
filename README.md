# Ballio Privacy Policy


Ballio does not create user accounts or store personal data on our own servers.

Ballio uses Unity Ads, which may collect advertising identifiers, device information, approximate location, diagnostics, and ad interaction data. Unity controls deletion requests for data collected through Unity Ads.

To request deletion of data related to Ballio, contact us at:
escaperstudios@gmail.com

For data collected by Unity Ads, you may also submit a privacy request through Unity’s Privacy Policy:
https://unity.com/legal/privacy-policy
